# /kickoff - Greenfield Discovery Interview

Execute the Greenfield Project Kickoff Protocol:
1. Read `.ai/standards/project-kickoff.md` and `.ai/standards/ui-ux-principles.md`.
2. Do NOT output code or create folders yet.
3. Ask the user the 5 targeted discovery questions (Purpose & Archetype, Audience & Density, Visual Mood, Framework/Ecosystem, Scope/MVP).
4. Ask for the target country (sets currency, number separators and phone mask) and the default theme (Claro / Oscuro / Sistema). Both themes are always built.
5. Wait for the user's answers before proposing the architecture and folder hierarchy.
6. When scaffolding, install `npx devforge add formatters` and `npx devforge add theme` before the first screen.
