# /kickoff - Greenfield Discovery Interview

Execute the Greenfield Project Kickoff Protocol:
1. Read `.ai/standards/project-kickoff.md`, `.ai/standards/ui-ux-principles.md`, `.ai/standards/theming.md` and `.ai/standards/data-formatting.md`.
2. Do NOT output code or create folders yet.
3. Ask the 7 questions of the protocol, in order, in two phases (do not skip or merge them):
   - Phase 1: (1) Project type & core problem, (2) Developer level, (3) Country & localization (default República Dominicana), (4) Stack recommendation + user confirmation.
   - Phase 2: (5) Audience & information density, (6) Visual identity + default theme (Claro / Oscuro / Sistema — both themes are always built), (7) MVP scope (2-3 key flows).
4. Ask in the user's language. Wait for each phase's answers; never assume answers the user did not give.
5. Summarize the agreed decisions and get confirmation before proposing the architecture and folder hierarchy.
6. When scaffolding, install `devforge add formatters` and `devforge add theme` before the first screen.
